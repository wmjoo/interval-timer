# 인터벌 트레이닝 타이머 🏃‍♂️⏱️

운동과 휴식을 번갈아가며 타이머를 제공하는 웹 애플리케이션입니다.

## ✨ 주요 기능

- **원형 진행률 표시**: 시각적으로 남은 시간을 확인할 수 있는 원형 타이머
- **운동/휴식 구분**: 운동 시간과 휴식 시간을 명확하게 구분하여 표시
- **세트 관리**: 총 세트 수를 설정하고 현재 진행 상황을 도트로 표시
- **사운드 알림**: 단계 전환 시 장음 호른, 종료 3초 전 카운트다운 틱
- **배경음악 플레이어**: 이전/재생·일시정지/다음 컨트롤과 재생목록 드롭다운
- **재생 모드**: 순차재생 / 한곡반복 / 랜덤 토글
- **SPLIT 모드**: 켜면 운동 구간엔 고강도, 휴식 구간엔 chill 트랙으로 분리 (기본 꺼짐)
- **음소거 기능**: 필요에 따라 소리를 끌 수 있는 토글 버튼
- **반응형 디자인**: 모바일과 데스크톱에서 모두 사용 가능
- **현재 시각 표시**: 화면 상단에 현재 시각 표시

## 🚀 사용법

1. **운동 시간 설정**: 운동할 시간을 초 단위로 설정 (기본값: 40초)
2. **휴식 시간 설정**: 휴식할 시간을 초 단위로 설정 (기본값: 20초)
3. **세트 수 설정**: 총 운동할 세트 수를 설정 (기본값: 5세트)
4. **시작**: "시작" 버튼을 클릭하여 타이머 시작
5. **일시정지/재개**: 필요시 일시정지하고 재개 가능
6. **리셋**: 언제든지 처음부터 다시 시작 가능

## 🎨 UI 특징

- **그라데이션 배경**: 깊이감 있는 파란색 그라데이션
- **글래스모피즘**: 반투명한 설정 패널과 버튼
- **부드러운 애니메이션**: 모든 전환과 호버 효과
- **색상 구분**: 운동(파란색)과 휴식(주황색) 단계별 색상
- **5초 경고**: 남은 시간이 5초 이하일 때 빨간색으로 변경

## 🎵 오디오 기능

### 알림음

- **Web Audio API** 신스 보이스 — 디튠된 소우파 2개 + 옥타브 사인 + 서브 오실레이터를 로우패스에 통과
- **장음 호른**: 구간 전환 시 지속음 (운동 C5 / 휴식 F4 / 완료 C5+G5)
- **카운트다운 틱**: 구간 종료 3초 전부터 784Hz 단발음

### 배경음악

- 음원: [FreePD](https://freepd.com/) (Public Domain, 출처 표기 불필요) — 원 사이트는 2025년 폐쇄
- 알림음이 울리는 동안 배경음악 볼륨을 25%로 낮췄다가 복구 (덕킹)

두 가지 소스로 동작하며, 플레이어 좌상단 아이콘이 현재 소스를 표시합니다.

| 소스 | 아이콘 | 재생목록 | 비고 |
|---|---|---|---|
| **STREAM** | wifi | 67곡 | [Internet Archive 미러](https://archive.org/details/freepd)에서 스트리밍 (기본값) |
| **LOCAL** | 모니터 | 12곡 | `audio/`의 자체 사본 (96kbps AAC) |

스트리밍이 실패하면 세션 전체가 LOCAL 모드로 전환되고 재생목록도 12곡으로 교체됩니다.
곡별로 폴백하지 않는 이유는, 그럴 경우 로컬 사본이 없는 55곡이 재생 불가 항목으로
드롭다운에 남기 때문입니다.

`audio/`의 음원은 아카이브 원본(320kbps MP3)을 macOS `afconvert`로 재인코딩한 것입니다.

```bash
afconvert -f m4af -d aac -b 96000 -s 0 input.mp3 output.m4a
```
